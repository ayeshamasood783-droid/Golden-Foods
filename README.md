# 🍔 GOLDEN FOODS — Premium Fast Food Website

GOLDEN FOODS is a modern, ultra-responsive, and high-performance fast-food ordering website. Built with custom HTML5, CSS3, and JavaScript, it offers a seamless digital menu experience and an instant **WhatsApp Checkout System** that allows customers to place orders directly without needing a complex backend or payment gateway.

---

## ✨ Features

* 📱 **100% Mobile Responsive:** Optimized for all screen sizes (mobile phones, tablets, and desktop displays) with a smooth slide-out navigation menu.
* 🛒 **Dynamic Cart & Order System:** Live total/subtotal calculation, item quantity adjustments, and a clear-all option.
* 💬 **Direct WhatsApp Checkout:** Automatically builds a formatted order summary (including items, quantities, totals, and delivery address) and redirects to WhatsApp.
* 🎯 **Category Filtering:** Filter food items seamlessly by categories (*Loaded Fries, Shawarma, Rolls, Burgers, Fries, Snacks*).
* 🎨 **Dark & Gold Premium UI:** Designed with modern glassmorphism, ambient background glows, floating food cards, and micro-interactions.
* ⚡ **Zero Framework Overhead:** Built using pure Vanilla JavaScript for maximum speed and efficiency.

---

## 🛠️ Tech Stack & Dependencies

* **Frontend:** HTML5, CSS3 (Flexbox & CSS Grid), JavaScript (ES6+)
* **Icons:** [FontAwesome 6](https://fontawesome.com/) (CDN)
* **Fonts:** [Google Fonts](https://fonts.google.com/) (*Syne* & *Plus Jakarta Sans*)
* **Images:** [Unsplash](https://unsplash.com/) CDN placeholders
